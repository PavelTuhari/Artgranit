# SEOForge — формат файлов импорта

Коннекторов к рекламным кабинетам и Google Search Console в этой версии нет,
поэтому факт поступает вручную или CSV-файлами. Когда коннекторы появятся,
они будут писать те же поля в те же таблицы — формат менять не придётся.

## Как устроен импорт

Два шага, и это не формальность:

1. **Предпросмотр** разбирает файл и показывает, что именно будет записано:
   разобранные строки, ошибки с номерами строк файла, найденные дубли.
   **Ничего не пишет в базу.**
2. **Загрузка** создаёт партию в `YSEO_IMPORT` и пишет строки. Дубли
   пропускаются молча, их число попадает в `ROWS_SKIPPED`.

Кнопка «Загрузить» неактивна, пока не сделан предпросмотр.

Ошибка в одной строке не отменяет весь файл: битая строка попадает в список
ошибок, остальные читаются дальше. Отвергается файл целиком только при
структурной ошибке — он пуст или в нём нет обязательных колонок.

## Общие правила

- **Разделитель** определяется по строке заголовка: `;`, табуляция или `,`.
- **Десятичный разделитель** — точка или запятая, принимаются оба.
- **Даты** — строго `YYYY-MM-DD`. `25/08/2026` будет отвергнута.
- **Кодировка** — UTF-8 (BOM снимается) либо CP1251.
- **Регистр заголовков** не важен, порядок колонок — тоже.
- Пустые строки пропускаются.
- Период (`YYYY-MM`) не указывается: он вычисляется из даты.

## Дедупликация: `EXT_ID`

`EXT_ID` — ключ, по которому строка узнаёт саму себя при повторной загрузке.

- Если колонка `ext_id` заполнена, значение берётся как есть — так стоит
  делать, когда выгрузка несёт собственный идентификатор строки.
- Если колонка пуста, ключ собирается детерминированно из источника, даты,
  кампании, канала и сайта. Одна и та же выгрузка даст тот же ключ и через
  полгода.

Повторная загрузка того же файла не создаёт дублей: уникальный ключ по
`EXT_ID` в таблице фактов не даст этого сделать, даже если ошибётся интерфейс.

## Расходы рекламы (`SPEND`)

Колонки: `site`, `channel`, `article`, `campaign`, `spend_date`, `suma`,
`valuta`, `clicks`, `impressions`, `conversions`, `revenue`, `ext_id`.

| Колонка | Обяз. | Значение |
|---|---|---|
| `site` | да | домен сайта, как он заведён в модуле (`officeplus.md`) |
| `channel` | да | ключ канала из справочника (`GOOGLE_ADS`, `META_ADS`, `FACEBOOK`…) |
| `article` | да | ключ статьи бюджета (`ADS`, `CONTENT`, `LINKBUILDING`…) |
| `campaign` | нет | код кампании (`utm_campaign`); пустое — расход без кампании |
| `spend_date` | да | дата расхода, `YYYY-MM-DD` |
| `suma` | да | сумма расхода, неотрицательная |
| `valuta` | нет | по умолчанию `MDL`; для остальных валют нужен курс в справочнике |
| `clicks` | нет | целое, по умолчанию 0 |
| `impressions` | нет | целое, по умолчанию 0 |
| `conversions` | нет | целое, по умолчанию 0 |
| `revenue` | нет | выручка, приписанная расходу; нужна для ROI |
| `ext_id` | нет | собственный ключ строки |

Пример:

```csv
site;channel;article;campaign;spend_date;suma;valuta;clicks;impressions;conversions;revenue;ext_id
officeplus.md;GOOGLE_ADS;ADS;back_to_school_2026;2026-08-25;1250,50;MDL;300;15000;12;8400;
officeplus.md;META_ADS;ADS;back_to_school_2026;2026-08-25;640.00;MDL;180;22000;7;3100;
una.md;GOOGLE_ADS;ADS;;2026-08-25;300;MDL;95;4100;3;0;gads-una-2026-08-25
```

## Метрики сайта (`METRICS`)

Колонки: `site`, `metric`, `channel`, `fact_date`, `value`, `source`, `ext_id`.

| Колонка | Обяз. | Значение |
|---|---|---|
| `site` | да | домен сайта |
| `metric` | да | ключ метрики: `POSITION_AVG`, `IMPRESSIONS`, `CLICKS`, `CTR`, `SESSIONS`, `USERS`, `CONVERSIONS`, `REVENUE`, `INDEXED_PAGES`, `BACKLINKS`, `TOP10_KEYS`, `CWV_LCP` |
| `channel` | нет | ключ канала, если метрика канальная |
| `fact_date` | да | дата, `YYYY-MM-DD` |
| `value` | да | значение; **может быть отрицательным** — дельта позиции или падение трафика |
| `source` | нет | откуда данные: `gsc`, `ga4`, `ahrefs`, `ручной` |
| `ext_id` | нет | собственный ключ строки |

Пример:

```csv
site;metric;channel;fact_date;value;source;ext_id
una.md;POSITION_AVG;GOOGLE_ORGANIC;2026-08-25;7.4;gsc;
una.md;CLICKS;GOOGLE_ORGANIC;2026-08-25;412;gsc;
una.md;TOP10_KEYS;;2026-08-25;38;ручной;
officeplus.md;CTR;GOOGLE_ORGANIC;2026-08-25;-1.5;gsc;
```

## Частые ошибки

| Сообщение | Что делать |
|---|---|
| `Отсутствуют обязательные колонки: SPEND_DATE` | в заголовке нет колонки; проверьте разделитель |
| `suma: не число ('1 250,50 MDL')` | уберите валюту и пробелы из ячейки суммы |
| `spend_date: ожидается дата YYYY-MM-DD ('25/08/2026')` | приведите даты к ISO-формату |
| `suma: отрицательное значение` | возвраты и корректировки в этой версии не поддержаны |
| `RO: Lipseste cursul valutar pentru EUR` | внесите курс EUR в справочнике курсов |
| `RO: Cheltuiala depaseste bugetul planificat` | режим `BLOCK`: увеличьте план или переключите на `WARN` |

Если сайт, канал, статья или метрика не найдены в справочниках, строка
не запишется — проверьте, что домен заведён точно так же, как в файле,
а ключи взяты из справочника.

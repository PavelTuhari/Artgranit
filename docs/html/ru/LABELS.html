Этикетки: Zebra (ZPL), TSC (TSPL), PDF A4 и PDF-рулон

Русский · Română · English

Есть одна запись этикетки (LabelData) и четыре выхода из неё. Содержание везде одинаковое:

┌──────────────────────────────────────┐
│ MY STORE                             │  бренд (Настройки → Бренд)
│ Футболка базовая оверсайз            │  название модели
│ Белый   TSH0001-001-S                │  цвет + SKU
│ ┌───┐                                │
│ │ S │                     179.90 MDL │  размер в рамке, цена
│ └───┘                                │
│        ▌▌▌▌▌▌▌▌▌▌▌▌▌▌▌▌▌▌▌▌          │  EAN-13
│        2 000000 000015               │
│ 100% хлопок                          │  состав
└──────────────────────────────────────┘

Язык названия цвета (Чёрный / Negru / Black) выбирается в «Настройки → Язык названий цветов на этикетке». На том же языке печатаются название модели и состав, если в карточке есть их перевод; иначе — основное название.

Какой формат выбрать

Формат Принтер Как печатать Когда
ZPL Zebra GK420t/d, ZD220, ZD230, ZD421, ZT230/ZT410, а также принтеры с ZPL-эмуляцией (Godex, Xprinter, TSC в режиме ZPL) tcp://IP:9100, cups://ОЧЕРЕДЬ или скачать .zpl основной поток, быстрее всего
TSPL TSC TE200/TE210/TE300, TTP-244 Pro, DA200/DA210, Alpha-3R; многие недорогие китайские принтеры (Xprinter XP-360B и похожие) то же если принтер не понимает ZPL
PDF A4 любой лазерный или струйный принтер открыть PDF → печать в масштабе 100% («Фактический размер») нет термопринтера, есть листы самоклеящихся этикеток
PDF рулон любой принтер с драйвером, в том числе Zebra/TSC через драйвер Windows (Seagull), а также виртуальный «Microsoft Print to PDF» одна страница = одна этикетка, размер страницы равен размеру этикетки печать через драйвер, архив, отправка по почте

Адрес принтера

Адрес задаётся в «Настройках» (printer_zpl, printer_tspl) или прямо в поле «Принтер» на странице этикеток.

Адрес Что происходит
tcp://192.168.1.50:9100 сырые байты уходят на порт 9100 (RAW / JetDirect). Так работают Zebra и TSC с Ethernet или Wi-Fi
cups://Zebra_ZD220 lp -d Zebra_ZD220 -o raw — для USB-принтера на Linux или macOS
dir:///home/shop/spool файл задания сохраняется в папку, откуда его заберёт другой скрипт или драйвер

USB-принтер на Linux/macOS (CUPS)

lpinfo -v | grep -i usb                       # найти URI принтера
sudo lpadmin -p Zebra_ZD220 -E -v "usb://Zebra%20Technologies/ZTC%20ZD220-203dpi%20ZPL" -m raw
# в TexFlow: cups://Zebra_ZD220

USB-принтер на Windows

Подходят два способа:

  1. PDF рулон через установленный драйвер принтера: в настройках драйвера задать размер бумаги 58×40 мм, при печати масштаб 100%.
  2. Сырой ZPL/TSPL. Открыть общий доступ к принтеру (например, имя ZEBRA), скачать .zpl и выполнить copy /b labels.zpl \\localhost\ZEBRA.

Если у принтера есть сетевой порт, проще всего tcp://IP:9100.

Размеры и разрешение

Настраиваются в «Настройках»:

Параметр По умолчанию Комментарий
Ширина × высота 58 × 40 мм популярные размеры: 58×40, 58×30, 40×30, 50×30, 43×25
Зазор 2 мм для TSPL (GAP)
DPI 203 203 / 300 / 600. Для ZPL модуль штрихкода 2 точки при 203 dpi и 3 точки при 300 dpi

Размеры в ZPL пересчитываются в точки: при 203 dpi 58 мм дают ^PW463, 40 мм — ^LL319.

Кириллица на термопринтере

Встроенные шрифты Zebra (^A0) и TSC ("1"…"8") не содержат кириллицы. Поэтому по умолчанию текст на ZPL/TSPL-этикетке транслитерируется: «Футболка» → «Futbolka». Цифры, цена, SKU и штрихкод от этого не меняются.

Чтобы печатать кириллицу:

  1. Загрузить TTF-шрифт в принтер: Zebra Setup Utilities → Download Fonts, у TSC — Diagnostic Tool → Font.
  2. В «Настройках» указать имя шрифта на принтере: - ZPL: E:ARIAL.TTF (тогда используется ^A@N,h,w,E:ARIAL.TTF; кодировка UTF-8 уже включена через ^CI28); - TSPL: ARIAL.TTF (используется CODEPAGE UTF-8 и TEXT x,y,"ARIAL.TTF",...).

В PDF кириллица печатается всегда: подключается системный шрифт DejaVu, Liberation или Arial. Свой шрифт можно указать переменной TEXFLOW_PDF_FONT.

Лист A4 — калибровка

По умолчанию лист 3×8 = 24 этикетки 70×37 мм (самый распространённый формат). Другие форматы:

Лист Колонок × строк Этикетка, мм Отступ сверху, мм
24 шт 3 × 8 70 × 37 0.5
21 шт 3 × 7 70 × 42.3 0.5
40 шт 4 × 10 52.5 × 29.7 0
14 шт 2 × 7 105 × 42.3 0.5
65 шт 5 × 13 38.1 × 21.2 10.7 (и слева 4.7)

Порядок калибровки:

  1. Напечатать на обычной бумаге с рамкой (Настройки → «Рамка»).
  2. Положить лист поверх листа этикеток на просвет.
  3. Сдвиг исправить отступами.

Поле «Начать с ячейки» позволяет допечатать начатый лист: например, 5 пропустит первые пять занятых этикеток.

Проверка без принтера

  • ZPL: страница этикеток показывает ZPL первой этикетки. Его можно вставить в https://labelary.com/viewer.html (8 dpmm = 203 dpi, 2.28×1.57 дюйма = 58×40 мм).
  • TSPL: скачать .tspl и открыть в TSC Console / Diagnostic Tool, либо отправить на принтер командой nc 192.168.1.50 9100 < labels.tspl.
  • PDF: открыть в браузере и отсканировать штрихкод с экрана телефоном.

^CI28
^PW463
^LL319
^LH0,0
^FO15,15^A0N,23,23^FH^FDMY STORE^FS
^FO15,45^A0N,31,31^FB433,1,0,L^FH^FDFutbolka bazovaya oversayz^FS
^FO15,83^A0N,23,23^FH^FDBelyy  TSH0001-001-S^FS
^FO15,117^GB86,60,2^FS

^FO112,121^A0N,54,54^FB336,1,0,R^FH^FD179.90 MDL^FS

Пример TSPL

SIZE 58 mm,40 mm
GAP 2 mm,0 mm
DIRECTION 1
REFERENCE 0,0
CODEPAGE UTF-8
SET TEAR ON
CLS
TEXT 15,15,"2",0,1,1,"MY STORE"
TEXT 15,42,"3",0,1,1,"Futbolka bazovaya oversayz"
TEXT 15,77,"2",0,1,1,"Belyy  TSH0001-001-S"
BOX 15,108,102,163,2
TEXT 26,115,"5",0,1,1,"S"
TEXT 125,115,"5",0,1,1,"179.90 MDL"
BARCODE 46,179,"EAN13",76,1,0,2,2,"200000000001"
TEXT 15,288,"2",0,1,1,"100% hlopok"
PRINT 1,1

Количество копий задаётся одной командой: ^PQn в ZPL и PRINT 1,n в TSPL. Поэтому 18 одинаковых этикеток — это одно задание, а не 18.

# superoffice.md — импорт в каталог

Заведено 12.09.2026. Коннектор: `scripts/superoffice_fetch.py`.

## Откуда берутся данные

Обход сайта, **не карта сайта**: их `sitemap.xml` от 2020 года, половина
ссылок отдаёт 404 (проверено). Категории читаются с главной, товары — со
страниц категорий с постраничной навигацией. Страницы отдаются сервером
целиком, JS не нужен. `robots.txt` ничего не запрещает.

Поля из разметки карточки:

| Поле | Где в HTML |
|---|---|
| Артикул | `<div class="product-article">Art: PT-1157-black</div>` |
| Название | `<h1>` |
| Цена поставщика | `<meta itemprop="price" content="3.55">` — это «Preț nou» |
| Цена до скидки | `<span class="high-price">` — их «Preț cu TVA» |
| Бренд | `Producator:` |
| Наличие | `Disponibilitate:` |
| Группа / категория | хлебные крошки Schema.org — **не** адрес: там транслит («papki-dlya-dokumentov»), а дереву нужна румынская денумире |

## Цена

Решение владельца 12.09.2026: **проценты складываются**.

```
розница = цена поставщика × (1 + 5% + процент рассрочки)
```

Процент рассрочки — тот же, что берёт витрина: беспроцентный пакет с
минимальной наценкой. Сейчас это **Liber Card / 3 rate = 5%**, работает
**от 115 лей** (`TMS_CREDITE_PLAN`, `ANNUAL_PCT = 0`). Ниже этой суммы
магазин рассрочку не предлагает — значит и добавлять нечего, там только +5%.

Итого: до 115 лей — ×1,05, выше — ×1,10. Параметры меняются ключами
`--markup`, `--rate-pct`, `--rate-min`.

Цену в рассрочку в файл НЕ кладём: витрина считает её сама (`rateBest`),
и дублировать значит рисковать расхождением.

## Запуск

```bash
python3 scripts/superoffice_fetch.py --cats 2 --out проба.xlsx    # проба
python3 scripts/superoffice_fetch.py --all --out SUPEROFFICE.xlsx # весь каталог
```

Скорость ~1,3 страницы в секунду, весь каталог ≈ 2,8 часа.

## Дальше — штатным конвейером

Файл ложится в `Set_data_import/17/` и грузится как любой другой источник:
`biro26pt_loader.py` → `BIRO26PT_importData.import_file(p_src => 'SUPEROFFICE')`.
Перед первым импортом источник надо завести в `TMS_ORG_IMPSRC` (префикс
артикула, алгоритм) — см. `IMPORT_SURSE.md`.

**Внимание к артикулам.** У них встречаются короткие и числовые («3878»),
а по правилу источника такие получают префикс — иначе столкнутся с
артикулами других поставщиков (инцидент officeshop, 629 ложных совпадений).

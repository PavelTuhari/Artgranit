ALL-IN-ONE BRIEF

Back + Front + Oracle ERP + Contabilitate + E-comm — de ce un singur sistem

O singură sursă de adevăr
Catalogul de pe site este TMS_UNIVERS. Prețul de pe site este perioada activă din TPR1D_PERPRLIST. Nu există sincronizări nocturne care pot rămâne în urmă.
Comanda = document contabil
Clic pe „Comandă" creează TMDB_DOCS cu aceleași triggere și numerotare ca un cont scris de operator în UNA.md. Contabilitatea îl vede imediat, cu rezerva pe 9301.
Rezistent la căderi
Adresa publică stă în Oracle Cloud; magazinul real — în oficiu, pe LAN-ul bazei (2–3 s pe pagină). Când oficiul se stinge, nginx trece singur pe copia din cloud (@spare), fără schimbări de DNS sau la MAIB.
Versiune
TMS_WebAppVers în Oracle și MySQL, valoare = data release-ului + hash surse
Setări
în YBIRO_SETTINGS, nu în cod — rescrierea unui fișier nu pierde valori
Documentație
servită din repository: /UNA.md/orasldev/b26docs/ (62 documente)
Backup
YBIRO_BACKUP_DEST + pagina biro26-backups

IMPLEMENTARE

Realizare Tehnică în Python / Flask

Spre deosebire de o platformă PHP clasică, aici un singur proces Flask servește portalul intern (Oracle ADB, thin) și magazinul (Oracle 11g, thick) — cele două drivere nu pot coexista în același proces, de aceea există worker-ul.

Arhitectură Completă (3+ Layere)

  1. Prezentare — Jinja2 + JS vanilla; fără CDN-uri în vitrină (mobil, rețea slabă); i18n RO/RU (biro26_i18n, YBIRO_GRP_I18N).
  2. Rute — app.py pentru modulele vechi; core/module_loader.py montează automat orice modules/<cheie>/ cu blueprint la /UNA.md/orasldev/<cheie>.
  3. Domeniu — models/biro26_<temă>.py, un fișier pe temă (regula №2: logica nu intră în fișiere comune).
  4. Date — Biro26Store → Biro26DB → subproces biro26_worker.py: contract JSON {success, columns, data, rowcount, message}; execute_query / execute_dml / execute_script / call_proc.
  5. Oracle — pachete PL/SQL pentru tot ce e tranzacțional; Python nu scrie niciodată „manual" în TMDB_DOCS.

Implementare Reală a Funcționalităților Site-ului

  • Catalog cu arbore, branduri multiple, preț la dată, carduri compacte, „Produsul zilei", căutare Oracle Text
  • Coș + prag 1 500 lei pentru rate (server-side) + transport în modalul plății Standard
  • Cont client, cabinet: facturi, acte de verificare pe note de livrare, dosare de credit
  • MAIB Checkout, EasyCredit Request_v3, Liber Card; log tehnic pentru clienții marcați admin
  • PDF cont / comandă în două motoare; designer vizual pdfme
  • Program de lucru real în banner (L–V 09–18, S 09–15, D liber, Europe/Chisinau)
  • Back-office 9 file cu ghid „?" pe fiecare; import fișiere cu dry-run
  • Failover automat, versiune în două baze, wp-login pe adresă secretă

Concluzii despre Realizarea Tehnică

  • Oracle-first: nicio stare autoritativă în JSON / SQLite / KV generic; tabele normalizate cu prefix (YBIRO_, BIRO26_, TMS_CREDITE_).
  • 11g impune disciplină: fără OFFSET/FETCH (paginare ROWNUM), fără IDENTITY (secvență + trigger), doar bind-uri; CLOB bind ultimul (ORA-24816).
  • Izolare: module noi doar în modules/<cheie>/ cu teste de izolare; fișierele comune primesc un singur rând de apel.
  • Operare: deploy punctual (patch de fișiere, md5 înainte de a atinge o platformă), systemctl restart artgranit, verificare /cos → 200 după orice schimbare.

def submit_request(env, req):
    base = f"https://api.ecredit.md/{env}/"
    body = {"request": {
        "Login": cfg.login, "Password": cfg.password,
        "Product": 54, "UIN": req.idnp,
        "ApDateOfBirth": req.dob, "ApFirstName": req.first,
        "ApLastName": req.last, "CaMobile": req.phone,
        "GoodsName": req.goods, "CreditAmount": req.amount,
        "NumberOfInstallments": req.months,   # 6..11
        "FirstInstallmentDate": req.first_pay}}
    r = post(base + "Request_v3", json=body)
    j = r.json()
    # 4xx fără plicul {request,response} = eroare de transport
    if r.status_code >= 400 and "response" not in j:
        return None, f"HTTP {r.status_code}: {j.get('detail')}"
    urn = j["response"]["URN"]
    store.save_req(req, urn); store.log_api(body_masked, j)
    return urn, None

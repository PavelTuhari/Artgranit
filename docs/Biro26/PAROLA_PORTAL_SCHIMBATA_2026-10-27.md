# Пароль портала сменён, подстановка логина и пароля убрана

*27.10.2026 · решение владельца: «да» на предложение убрать подстановку и сменить пароль ADMIN*

## Что было

Страница входа `/login` (nufarul.eminescu.md, облако, офис) подставляла в поля
`DEFAULT_USERNAME` и `DEFAULT_PASSWORD` из `.env` — логин ADMIN и пароль видел любой, кто
открывал страницу. Тот же пароль лежал в публичном репозитории GitHub
(`PavelTuhari/Artgranit`, PUBLIC): `.env.example`, `install.py`, `test_agro_crud.py`.

Пароль портала **не совпадает** с паролем базы (`DB_PASSWORD`) — база не затронута.

## Что сделано

| Шаг | Где |
|---|---|
| Поля логина и пароля на `/login` больше никогда не заполняются | `models/login_mode.py` (`prefill` всегда `False`), тесты `tests/test_login_mode.py` |
| Новый пароль (20 символов, случайный) в `DEFAULT_PASSWORD` | `.env` на nufarul, облаке и офисе; копии `.env.bak-2026-10-27` рядом |
| Новый пароль хранится только в связке ключей Mac владельца | служба `artgranit-portal-admin`, учётная запись `ADMIN` |
| Старый пароль убран из файлов репозитория | заглушки в `.env.example`, `install.py`, `test_agro_crud.py` читают переменные окружения |

Прочитать новый пароль:

```bash
security find-generic-password -s artgranit-portal-admin -a ADMIN -w
```

## Проверка (27.10.2026)

- `/login` на всех трёх серверах — 200, полей с подставленными значениями — 0, Traceback — 0.
- https://nufarul.eminescu.md/login и https://officeplus.una.md/login — пустые поля.
- Хеш нового пароля в `.env` всех трёх серверов одинаковый.

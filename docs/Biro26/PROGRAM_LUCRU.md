# Расписание работы в шапке сайта

Сделано 31.08.2026.

## Что было не так

В шапке стояла **статическая строка** из словаря переводов:
`Astăzi lucrăm de la 09:00 până la 19:00` — одна и та же фраза в понедельник
и в воскресенье. График не вычислялся вообще, поэтому был неверным почти
каждый день, и час закрытия тоже был чужой (19:00 вместо 18:00).

## Как работает теперь

График считается на сервере по дню недели и берётся из настройки.

| День | Что показывается |
|---|---|
| Пн–Пт | `Astăzi lucrăm de la 09:00 până la 18:00` |
| Суббота | `Astăzi lucrăm de la 09:00 până la 15:00` |
| Воскресенье | `Astăzi este zi liberă` / «Сегодня выходной» |

**Настройка:** `YBIRO_SETTINGS.SHOP_HOURS`

```
1-5=09:00-18:00;6=09:00-15:00;7=
```

День 1 = понедельник … 7 = воскресенье (как ISO). Пустое значение = выходной.
Сломанный фрагмент игнорируется — ошибка в настройке не оставит витрину без
шапки. Менять часы можно без правки кода.

## Два решения, которые важны

**Время по Кишинёву, а не по браузеру.** Иначе посетитель из другого часового
пояса поздно вечером видел бы график завтрашнего дня.

**Атрибут `data-t` с элемента снят.** Механизм переводов заменяет текст по
словарю; если оставить `data-t`, он затрёт вычисленную строку обратно
фиксированной фразой. Обе языковые версии лежат в `data-hours-ro` /
`data-hours-ru`, переключение языка берёт их оттуда.

## Файлы

| Файл | Что там |
|---|---|
| `app.py` | `_biro26_hours_parse` / `_biro26_hours_text` + две строки в контексте |
| `templates/biro26/site_base.html` | `<span id="topbar-hours">` с `data-hours-*` |
| `static/biro26/site.js` | в `applyLang` — подстановка версии по языку |

## Как проверить

```bash
curl -s https://officeplus.md/ | grep -o 'data-hours-ro="[^"]*"'
```

Должна прийти строка на текущий день. В воскресенье — «zi liberă».

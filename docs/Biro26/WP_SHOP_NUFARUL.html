2. Маршрут biro26-1shop

  • В app.py у каждого маршрута biro26-site/* добавлен алиас /UNA.md/orasldev/biro26-1shop[/...] — те же view-функции и static/biro26/*.
  • Красивые ссылки (/catalog, /cos, /produs/N…) существуют только за nginx officeplus.md. На nufarul их переводит клиентский шим в static/biro26/site.js: SITE_PREFIX + siteURL() (маппинг pretty → Flask: /cos→/cart, /cont→/account, /produs/N→/product/N, /favorite→/favorites, /compara→/compare, /branduri→/brands, прочее→/page/<slug>) + перехватчик кликов, переписывающий href на лету.

3. Копия WordPress (biro26-wp)

Файлы

  • /var/www/officeplus/ — public_html из web/shop2.officeplus.md/domain_data.tar.zst; наш wp-config.php сохранён поверх (chmod 640).
  • Симлинк /var/www/wpuna/UNA.md/orasldev/biro26-wp → /var/www/officeplus — путь на диске совпадает с URI.
  • Откат: файлы /var/www/officeplus.main/ (копия ОСНОВНОГО WP officeplus.md), БД /home/ubuntu/officeplus_wp_main_backup.sql.gz.

База данных

  • MariaDB officeplus_wp (utf8mb4/unicode_520_ci), пользователь officeplus_wp@localhost; пароль — только в wp-config.php.
  • Импортирована секция wordpress_shop2 дампа.
Грабли дампа. Дамп — мульти-БД (CREATE DATABASE wordpress / wordpress_shop1 / wordpress_shop2 + USE): при импорте секцию нужно вырезать и удалить CREATE DATABASE/USE, иначе данные молча уходят в другую БД. Импорт строго с --default-character-set=utf8mb4 — иначе эмодзи в контенте валят импорт (Incorrect string value).

Служебные страницы витрины shop1 (site-rechizite, site-plati, site-branduri, site-about[-ru/-en], site-contact, credite, credite-ru) в shop2-БД отсутствовали — перенесены из бэкапа основной БД (wp_posts/wp_postmeta, офсет ID +10000).

Замены URL в БД (wp search-replace, --all-tables)

  1. https://shop2.officeplus.md → https://nufarul.eminescu.md/UNA.md/orasldev/biro26-wp
  2. src="/biro26-shop" → src="/UNA.md/orasldev/biro26-shop" (iframe магазина)
  3. href="/biro26-shop" → аналогично
  4. "/biro26-backoffice" → "/UNA.md/orasldev/biro26-backoffice"

Корневые /biro26-* пути работали только через nginx-rewrite на officeplus; на nufarul корень уходит во Flask → «Not Found» внутри iframe.

nginx (/etc/nginx/sites-enabled/nufarul.eminescu.md)

location = /UNA.md/orasldev/biro26-wp { return 301 /UNA.md/orasldev/biro26-wp/; }
location ^~ /UNA.md/orasldev/biro26-wp/ {
    root /var/www/wpuna;
    index index.php;
    try_files $uri $uri/ /UNA.md/orasldev/biro26-wp/index.php?$args;
    client_max_body_size 16M;
    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php8.3-fpm.sock;
    }
}

Блок стоит ДО location / (proxy на Flask :8000).

5. Безопасность — компрометация живых WP

В БД из архива найдены бэкдор-администраторы: основная БД — 7 × wp2_*@wp2shell.invalid; shop2 — 45 (те же wp2_* + bob_*@bobresearchlabs.com). В локальной копии все удалены, остался только officeplus; PHP-файлов в uploads/ нет. Живые officeplus.md / shop1 / shop2 заражены теми же аккаунтами — после восстановления доступа обязательна чистка (или перезаливка из этой вычищенной копии). Возможная причина внезапного SSH-бана officeplus — активность бэкдоров.

5a. Liber Card: настройки через админку (инструкция для клиента)

Действующая конфигурация (2026-08-06): только «Liber Card / 6 rate» (наценка 8% + 10% организации), 3/4/5 rate выключены, максимум 50 000 лей (лимит карты MAIB Liber).

Всё меняется без программиста в кредит-админке /UNA.md/orasldev/biro26-credit-admin → организация Liber Card MAIB. БД общая — изменение действует сразу на officeplus.md и nufarul.

  1. Включить/выключить срок — галочка Activ у пакета «Liber Card / N rate». Выключенные пакеты не удаляются — их можно вернуть.
  2. Лимиты — поля Suma min / Suma max. ВАЖНО: проверяются по ФИНАНСИРУЕМОЙ сумме (цена × наценка): «до 50 000 финансируемых» ≈ до ~46 300 лей стандартной цены при 8%+10%.
  3. Наценка — Markup % пакета + Transport markup % организации (действующая цена в кредит = сумма двух). После изменения сверить витрины (CLAUDE.md, правило 7).
  4. Изменения подхватываются в течение 5 минут (кэш офферов); мгновенно — sudo systemctl restart artgranit.
  5. Организация пропала совсем → не осталось ни одного активного пакета (инцидент 2026-08-06) либо скрыта через BIRO26_CREDIT_HIDE_ORGS в .env.

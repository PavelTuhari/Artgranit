## 2. Фундамент (недели 1–2) — без этого реклама сливает деньги

1. **Лендинг платформы** — отдельная страница `artgranit.una.md` (или `/platforma` на officeplus.md): три блока под три группы, цифры, живое демо, форма «демо на ваших данных». Прототип — рекламный проспект (`PROSPECT_ARTGRANIT.md` / `artgranit-prospect.html`).
2. **Демо-контур** на nufarul.eminescu.md: гостевой вход «только чтение» в портал модулей + демо-магазин с обезличенными данными. Без этого разработчику и Oracle нечего показать.
3. **Публичный репозиторий-шаблон** `artgranit-module-template` (GitHub): ядро + один образцовый модуль + тесты изоляции + `new_module.py`. Полный код остаётся закрытым; открываем контракт и инструмент.
4. **Профили**: LinkedIn-страница компании, Telegram-канал «Artgranit / UNA.md dev», YouTube-канал, GitHub-организация. Facebook-страница OfficePlus уже есть — переиспользуем.
5. **Аналитика с согласием**: GA4 только после «Accept» (уже сделано), UTM-дисциплина (`utm_source` = канал, `utm_campaign` = группа).
6. **Юридическое**: политика конфиденциальности с разделом cookie (текст готов, ждёт публикации), договор-оферта на внедрение, прайс.

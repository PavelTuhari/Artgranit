# Artgranit — веб-платформа модулей над Oracle и учётной системой UNA.md

*Рекламный проспект · версия 1.0 · 17.10.2026 · RU (RO/EN-резюме в конце)*

> **Одна фраза.** Artgranit превращает учётную систему на Oracle в набор веб-модулей —
> магазин, CRM, кредиты, производство, мониторинг, — которые подключаются к общему
> ядру сами, не трогают чужой код и разворачиваются за один день. Живой пример —
> **officeplus.md**: интернет-магазин, у которого товары, цены, остатки и заказы
> живут прямо в ERP, без промежуточной базы.

## Почему это работает, когда другие «интеграции» ломаются

1. **Oracle-first.** Данные модуля — только в нормализованных таблицах Oracle со своим префиксом (`CRED_*`, `PAPI_*`, `EFA_*`). Никаких JSON-блобов, SQLite и «временных» файлов как источника правды.
2. **Ядро + изолированные модули.** Модуль — это папка `modules/<ключ>/`: маршруты, SQL, шаблоны, установщик DDL, тесты, документация. Общий код он не трогает вовсе — ядро находит его и подключает под своим адресом. Две команды, десять сессий ИИ-агентов — ни одного конфликта слияния.
3. **Меню собирается само.** Любая страница под `/UNA.md/orasldev/…` попадает в боковую панель и на карту системы автоматически.
4. **Документация — часть модуля.** Каждое изменение — свой `.md`; хаб документации собирает их сам. По документу работу можно восстановить, даже если код затёрли.
5. **Инженерные правила записаны и проверяются тестами**: изоляция модуля, отсутствие упоминаний в общем коде, DDL с `/` до и после каждого PL/SQL-блока, запрет `TRANSLATE` с диакритикой в CL8MSWIN1251, живые ссылки в ответах.
6. **Разработано с ИИ-агентами, под контролем человека.** Правила для агентов (`CLAUDE.md`, `AGENTS.md`) — это и есть инженерный стандарт проекта; каждый шаг — коммит и push, каждый инцидент — разобран и записан.

## Как выглядит внедрение

| Шаг | Срок | Что происходит |
|---|---|---|
| 1. Подключение к вашей Oracle | 1 день | wallet вне каталога деплоя, `.env`, systemd + nginx + Let's Encrypt |
| 2. Магазин / кабинет / модули | 1–3 дня | включаем нужные модули, DDL ставится своим установщиком, данные — ваши |
| 3. Интеграции | по списку | e-Factura, банки, кредиторы, Telegram, Zabbix — уже написаны, настраиваются из бэк-офиса |
| 4. Свой модуль | от 1 дня | `python scripts/new_module.py <ключ> "<Название>"` — каркас, тесты, документация, ветка, push |

the ERP database directly. 30 modules, 179 pages, 1355 tests, Oracle 11g and Autonomous

# Инструкция OpenVPN для сотрудников

Страница для сотрудника: как поставить OpenVPN Connect на компьютер или
телефон и подключиться к офисной сети.

| Где | Адрес |
|---|---|
| nufarul.eminescu.md | https://nufarul.eminescu.md/UNA.md/orasldev/vpnguide |
| Локально | http://127.0.0.1:3013/UNA.md/orasldev/vpnguide |

Страница под входом в портал, как и всё остальное.

## Почему отдельный модуль

Выдача доступов живёт в мониторинге офиса (`modules/netmon`), а мониторинг
намеренно выключен на публичных серверах: он показывает устройство сети и
выдаёт ключи. Инструкция же нужна всем сотрудникам, в том числе на nufarul.
Поэтому она вынесена в свой модуль, `modules/vpnguide/`, и работает везде.

**В инструкции нет ни адресов сети, ни ключей, ни имён серверов.** Всё, что
нужно для подключения, уже лежит в файле `.ovpn`, который администратор
выдаёт лично. Это правило для любых будущих правок страницы: если
понадобилось вписать адрес или пароль — значит, что-то не так с профилем.

## Что на странице

1. Получить файл `.ovpn` у администратора.
2. Поставить OpenVPN Connect — вкладки Windows, macOS, iPhone/iPad, Android,
   Linux. Вкладка своего устройства открывается сама (по браузеру).
3. Проверить подключение.
4. Правила: файл — личный ключ; потеря устройства — сразу к администратору.
5. Таблица неполадок.

Ссылки на клиент — только официальные, проверены 04.10.2026 (ответ 200):

* https://openvpn.net/client/
* https://apps.apple.com/app/openvpn-connect/id590379981
* https://play.google.com/store/apps/details?id=net.openvpn.openvpn

## Персональная ссылка на 15 минут

Добавлено 04.10.2026. Администратор при выдаче доступа (галочка в форме) или
позже (кнопка «Ссылка» у сертификата) делает ссылку вида

```
https://nufarul.eminescu.md/UNA.md/orasldev/vpnguide/s/<токен>
```

и отправляет её получателю. По ней открывается — **без входа в портал** —
инструкция на трёх языках (ru/ro/en, переключатель вверху):

1. прямые ссылки на OpenVPN Connect: Windows `.msi`, macOS `.dmg`, App Store,
   Google Play и сайт OpenVPN;
2. кнопка «Скачать <имя>.ovpn»;
3. шаги импорта и подключения;
4. **полный текст профиля** с кнопкой «Скопировать» и SHA-256 — если файл не
   скачивается, его соберёт сам человек или его помощник с ИИ;
5. правила обращения с ключом.

Для ИИ-агента есть та же инструкция простым текстом:
`…/s/<токен>/instructions.md`. Профиль в ней — между строками
`-----BEGIN OVPN PROFILE-----` и `-----END OVPN PROFILE-----`, а в HTML — в
`<script type="application/json" id="ovpn-data">` (имя файла, SHA-256,
содержимое).

### Срок и отзыв

* по умолчанию 15 минут, можно от 1 до 1440;
* после срока страница отвечает 410 «Ссылка больше не действует» на трёх
  языках, шифротекст в базе стирается;
* в панели мониторинга — таблица «Ссылки для получателей»: кому, когда,
  до какого времени, сколько раз открыта, скачан ли файл, последнее открытие;
  кнопка «Отозвать ссылку»;
* **отзыв сертификата гасит все его живые ссылки** автоматически.

### Как защищено

| Угроза | Защита |
|---|---|
| подбор ссылки | токен 256 бит (`secrets.token_urlsafe(32)`) |
| утечка базы | в базе только SHA-256 токена; профиль зашифрован ключом, выведенным из токена (HKDF-SHA256 → Fernet) — без ссылки не расшифровать |
| ссылка висит в почте годами | срок 15 минут, после него шифротекст стёрт |
| токен уходит в Referer на openvpn.net, Apple, Google | `Referrer-Policy: no-referrer` и такой же `<meta>` |
| кэш прокси, поисковики | `Cache-Control: no-store`, `X-Robots-Tag: noindex` |
| кто-то кроме получателя открыл | журнал открытий с IP и браузером, видно в панели |

### Две ловушки, на которые уже наступили

1. **Часовые пояса.** Ссылку создаёт машина администратора (Кишинёв), а
   проверяет nufarul (UTC). Сроки — `TIMESTAMP WITH TIME ZONE`, сравнение —
   внутри Oracle с `SYSTIMESTAMP`. С обычным `TIMESTAMP` ссылка жила бы на
   часы дольше или умирала бы сразу.
2. **Параллельный DML в Autonomous Database.** Удаление и обновление строк
   с внешним ключом давали `ORA-12860 deadlock … sibling row lock`. Каждый
   курсор модуля выключает параллельный DML (`store._cursor`).

### Oracle-объекты, префикс `VPNG_`

| Объект | Что |
|---|---|
| `VPNG_SHARES` | ссылка: кому, хэш токена, шифротекст, срок, кто создал, отзыв |
| `VPNG_SHARE_HITS` | журнал открытий (только добавление): страница, файл, текст |
| `VPNG_SHARES_SEQ`, `VPNG_SHARE_HITS_SEQ` + триггеры `*_BI` | идентификаторы |

Установка — своим установщиком, общий `deploy_oracle_objects.py` не трогается:

```bash
python modules/vpnguide/scripts/vpnguide_deploy.py
```

Поставлено в общую базу 04.10.2026, все объекты `VALID`.

### API (в панели мониторинга, под входом)

| Адрес | Что делает |
|---|---|
| `POST …/netmon/api/vpn/clients` `{"name", "share_minutes", "share_lang"}` | выдать доступ и сразу сделать ссылку |
| `POST …/netmon/api/vpn/clients/<имя>/share` `{"minutes", "lang"}` | ссылка на уже выданный сертификат |
| `GET …/netmon/api/vpn/shares` | список ссылок с журналом |
| `POST …/netmon/api/vpn/shares/<id>/revoke` | отозвать ссылку |

### Публичные адреса (без входа)

| Адрес | Что |
|---|---|
| `GET …/vpnguide/s/<токен>` | страница (`?lang=ru\|ro\|en`) |
| `GET …/vpnguide/s/<токен>/profile` | файл `.ovpn` |
| `GET …/vpnguide/s/<токен>/instructions.md` | текст для ИИ |

## Ссылка для доступа L2TP/IPsec (MikroTik)

С 06.10.2026 ссылкой выдаётся и доступ на маршрутизатор MikroTik — тип
`l2tp` (`VPNG_SHARES.KIND`). Файла профиля у L2TP нет, поэтому страница
другая (`vpnguide_share_l2tp.html`), а настройка собирается на лету:

| Адрес | Что |
|---|---|
| `…/s/<токен>/windows.ps1` | скрипт PowerShell: создаёт подключение и подключается |
| `…/s/<токен>/apple.mobileconfig` | профиль для macOS и iPhone с настроенным L2TP |
| `…/s/<токен>/instructions.md` | текст для ИИ, настройки — в JSON в конце |

В шифре лежат четыре значения: сервер, логин, пароль, общий ключ IPsec.
Строки в скрипте PowerShell — в одинарных кавычках: в двойных `$` и `` ` ``
из ключа превратились бы в код. Подробно —
[../Netmon/MIKROTIK.md](../Netmon/MIKROTIK.md).

Отзыв гасит ссылки только своего типа: имя сертификата OpenVPN может
совпасть с учёткой L2TP.

Установщик схемы теперь повторяемый — «уже есть» не считается ошибкой:

```bash
python modules/vpnguide/scripts/vpnguide_deploy.py   # 300 + 301
```

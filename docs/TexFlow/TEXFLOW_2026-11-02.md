# TexFlow — автономная приёмка одежды из мешков (2026-11-02)

## Что сделано

Создано отдельное автономное веб-приложение на Python, Flask и SQLite. Оно
закрывает весь путь одежды из мешков (Турция, Китай):

- поставка и импортные затраты;
- примерный упаковочный лист;
- разбор мешка по матрице «цвет × размер» в стиле Zara или сканером;
- сверка факта с листом;
- себестоимость и цены по наценкам;
- карточки и каталог;
- этикетки ZPL (Zebra), TSPL (TSC), PDF A4 и PDF-рулон.

## Почему отдельно от портала

Владелец попросил **автономное** приложение на **SQLite**. Правило
«Oracle-first» в `CLAUDE.md` относится к модулям портала Artgranit в `modules/`.
TexFlow к порталу не подключается, Oracle не использует и общий код не
трогает. Поэтому он лежит в `standalone/texflow/`, со своими тестами и
документацией.

## Затронутые файлы

Только новые пути:

- `standalone/texflow/**` — приложение, тесты, документация;
- `docs/TexFlow/TEXFLOW_2026-11-02.md` — этот файл.

Общие файлы (`app.py`, `deploy_oracle_objects.py`, `models/`, `controllers/`,
`templates/`, `sql/`) не изменены. Это проверяют тесты
`test_shared_app_py_does_not_mention_texflow` и `test_shared_deployer_untouched`.

# Обновление 1.1.0 — три языка (RU / RO / EN), 2026-11-02

## Что сделано

- **Интерфейс.** Все экраны, сообщения и ошибки переведены на русский, румынский
  и английский. Переключатель RU / RO / EN стоит в шапке и запоминается в
  браузере. Язык по умолчанию задаётся в «Настройках».
- **Справочники.** У цветов, групп цветов, категорий и размерных шкал есть
  колонки `name_ro` и `name_en`. Стартовые значения уже переведены
  (Negru/Black, Blugi/Jeans, Litere/Letter…). Базы версии 1.0 получают
  колонки и переводы автоматически при запуске; ручные правки при этом не
  затираются.
- **Модели.** Название и состав модели можно задать на RO и EN в карточке
  модели. Каталог, разбор и цены показывают их на языке интерфейса, поиск
  работает по любому языку.
- **Этикетки.** «Язык названий цветов на этикетке» определяет язык цвета,
  названия модели и состава на ZPL, TSPL и PDF.
- **Упаковочный лист.** Понимает румынские заголовки
  (`sac;categorie;descriere;cantitate;preț;greutate`) и румынские или
  английские названия категорий.
- **Документация на трёх языках:** README, инструкция оператора, этикетки и
  принтеры, блок-схемы Mermaid (21 схема, все отрисовываются), встроенная
  страница «Инструкция».

## Файлы

- новые: `texflow/i18n.py`, `texflow/i18n_catalog.py`,
  `templates/help_{ru,ro,en}.html`, `tests/test_i18n.py`,
  `README.{ro,en}.md`, `docs/*.{ro,en}.md`;
- изменённые: только внутри `standalone/texflow/`.

# 1.2.0 — нативное приложение Windows/macOS/Linux, самоустановка, Excel/CSV, редактор этикеток

## Что сделано

- **Ядро без Flask.** `texflow/` работает и под веб-версией, и под нативным приложением. Flask
  импортируется только в `create_app`.
- **Нативное приложение** `desktop/texflow_desktop/` (Python + Tkinter), 8 вкладок, RU/RO/EN:
  - поставки, разбор (сканер, матрица цвет × размер с клавиатуры), цены, каталог, этикетки;
  - **редактор этикеток**: холст в масштабе, мышь, стрелки, свойства, EAN-13/CODE128, рамки,
    линии, JSON;
  - **Excel / CSV**;
  - настройки.
- **Шаблоны этикеток** в таблицах `label_templates` и `label_template_elements`. Один шаблон
  печатается в ZPL, TSPL, PDF-рулон и на лист A4. Веб-версия выбирает шаблон на странице
  «Этикетки».
- **Excel / CSV** (`texflow/exchange.py`, вкладка в desktop и `/exchange` в вебе):
  - выгрузка 7 наборов и «полный отчёт»;
  - загрузка упаковочного листа, цен (правка в Excel и обратно), каталога (сразу в приёмку) и
    результатов приёмки;
  - заголовки на трёх языках.
- **Самоустановка**:
  - `Install-TexFlow-Windows.bat`, `Install-TexFlow-macOS.command`, `install-texflow-linux.sh`;
  - `install/install.py`: venv, ярлыки `.lnk` / `.app` / `.desktop`, удаление;
  - `texflow_app.py` сам доставляет библиотеки при первом запуске;
  - `install/build_exe.py` (PyInstaller) и шаблон GitHub Actions для сборки на трёх ОС.

# Сборка на каждый push и подпись unisim-soft

## Что сделано

- `.github/workflows/texflow-desktop.yml` — **единственный общий файл**, добавлен по прямому
  решению владельца. Запускается на каждый push с изменениями `standalone/texflow/` и на теги
  `texflow-v*`. Этапы:
  1. тесты;
  2. скриптовая версия с подписанным манифестом;
  3. запуск из скриптов на Windows / macOS / Linux (`--verify`, `--check`, `--smoke`, установщик);
  4. сборка `.exe` / `.app` / бинарника Linux и их запуск;
  5. `SHA256SUMS` + подпись Ed25519 **unisim-soft** + аттестация GitHub;
  6. выпуск `texflow-nightly` (push в `main`) или `texflow-vX.Y.Z` (тег).
- Выкачивается только `standalone/texflow` (sparse checkout): файл другого проекта
  `docs/Planograms/…/… ???_V-18.09.2026.docx` с `?` в имени не выкачивается на Windows.
- `texflow/integrity.py`:
  - Ed25519 на чистом Python (RFC 8032, сверено с `cryptography`);
  - манифест SHA-256;
  - статусы ok / unsigned / modified / bad-signature / dev.
- `texflow_app.py`:
  - самопроверка при запуске, `--verify`, `--verify-sums`;
  - `--smoke` для CI;
  - `TEXFLOW_STRICT_INTEGRITY=1` — запуск только подписанной поставки.
- Ключи:
  - открытый: `install/signing/unisim-soft.pub`, отпечаток `c5173c9670d69b5d`;
  - закрытый: **только** секрет репозитория `UNISIM_SOFT_SIGNING_KEY`, в git его нет
    (`.gitignore`: `*SIGNING_KEY*`).

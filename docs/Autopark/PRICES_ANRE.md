# Autopark: реальный архив предельных цен ANRE (FLT_FUEL_PRICES)

Собрано и загружено 2026-08-26. Период: 2024-09-01 .. 2026-08-26.

## Итог одной строкой

Полный дневной архив предельных цен ANRE по **A95** и **DIESEL** получен
целиком с официального источника anre.md: **по 500 реальных точек на
продукт** (все дни публикации, 2024-09-02 .. 2026-08-26, без единого
пропуска месяца). Модельная калибровка промежуточных точек удалена;
пропуски между решениями закрыты «ступенькой» (forward-fill), как того
требует сама природа предельной цены.

## Первоисточник и способ получения

Страницы истории anre.md ([Istoric Benzină 95](https://anre.md/benzina-95-3-2),
[Istoric Motorină](https://anre.md/motorina-3-3)) показывают в HTML только
скользящее окно ~12 дат, но их фильтр периода вызывает открытый
AJAX-эндпоинт:

```
GET https://anre.md/oil-get-table?firstDate=YYYY-MM-DD&secondDate=YYYY-MM-DD&fuelId=N
```

- `fuelId=2` — Benzina A95, `fuelId=3` — Motorina;
- ответ — JSON с HTML-таблицей «Data publicării … PC», где `PC`
  (`data-price`) — предельная цена розничной продажи, лей/л;
- глубина архива: datepicker страницы допускает даты с 2021-09
  (`minDate=1630540800000`), т.е. окно 2024-09..2026-08 покрыто целиком.

Архив снят помесячными запросами (24 месяца × 2 продукта, 48 запросов)
и сведён в реестр первичных точек
**`docs/Autopark/anre_prices_raw.csv`** (`date,product,price,source_url`,
1000 строк) — это доказательный артефакт: каждая строка несёт URL
запроса, которым она получена.

Контрольная сверка: значения совпали 1-в-1 со скользящим окном живых
страниц (напр. A95 25.08.2026 = 31.01; DIESEL 25.08.2026 = 33.32) и с
вехами ретроспективных статей ANRE (24.79 A95 в конце января 2025,
скачок 30.16/30.29 24-27.07.2026).

## Методика заполнения календаря

ANRE публикует предельную цену в рабочие дни; установленная цена
**действует до следующего решения**. Поэтому:

- **дни публикации** — буквальная цена ANRE (500 точек/продукт);
- **выходные/праздники между двумя решениями** — «ступенька»:
  повторяется последняя опубликованная цена (forward-fill, 224
  дня/продукт). Только между первой и последней реальной точкой,
  никакой экстраполяции за края.

`CK_FLT_FUEL_PRICES_SRC` допускает только `('ANRE','MODEL')`, поэтому
и дни публикации, и forward-fill несут `SOURCE='ANRE'` (менять DDL в
этой задаче нельзя — файл в зоне параллельной сессии). **Какие именно
дни первичны — определяет реестр `anre_prices_raw.csv`**: дата есть в
CSV → публикация ANRE; даты нет, но `SOURCE='ANRE'` → forward-fill.

- **2024-09-01** (воскресенье до первой публикации в окне) — единственный
  день A95/DIESEL вне реального архива: остаётся `MODEL`
  (откалиброван к ближайшему реальному якорю, чтобы не было шва).

## A92 / A98 — почему остаются MODEL

ANRE устанавливает предельные цены **только для бензина A95 и
дизтоплива** (плюс сжиженный газ) — A92 и A98 не входят в регулируемый
перечень, реального архива предельных цен для них **не существует в
природе**. Их ряд честно помечен `SOURCE='MODEL'` (725 дней каждый) и
не выдаётся за данные регулятора.

| Источник | Результат |

## Загрузка

```
venv/bin/python modules/autopark/scripts/autopark_prices.py \
    --anre-csv docs/Autopark/anre_prices_raw.csv --yes
```

Скрипт идемпотентен (executemany MERGE по `(PRICE_DATE, PRODUCT_CODE)`).
Живой прогон 2026-08-26: 2900 строк; по A95 и DIESEL перезаписано
с MODEL на ANRE по 704/706 строк соответственно (до загрузки реальными
были только 21/19 якорей задачи 4, после — по 724).

Проверка ступеньки (SELECT из FLT_FUEL_PRICES, A95, июльский скачок):

```
2026-07-24  30.16  ANRE   <- решение (пятница)
2026-07-25  30.16  ANRE   <- forward-fill (суббота)
2026-07-26  30.16  ANRE   <- forward-fill (воскресенье)
2026-07-27  30.40  ANRE   <- следующее решение
```

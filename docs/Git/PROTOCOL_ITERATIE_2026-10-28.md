## 2. Почему прежние правила не сработали

1. Они были **прозой на 700-й строке** `CLAUDE.md`. Агент читает верх файла (правило
   №1 про модули) и начинает работать; «push после шага» он встречает, когда шаг уже
   прошёл.
2. Они полагались на **hook**, а hook покрывает только `Write`/`Edit`. Режим auto
   прямо требует писать через shell — и hook молчит.
3. «Commit после шага» требовал 4 команд и выбора путей; под нагрузкой это
   откладывалось «до конца».
4. Не было **команды проверки**, которую можно выполнить не думая. Аудит из правила
   №6 — это цикл `for-each-ref` на три строки, его никто не запускал.

## 4. Протокол итерации — что считается «итерацией» и что после неё обязательно

**Итерация** — любое из: создан файл · правка общего файла · тест прошёл · проверка
вживую прошла · документ дописан. Не «фича готова», а **шаг**. Ориентир: не реже чем
каждые 20–30 минут и никогда больше 5 новых файлов без push.

После итерации — одна команда:

```bash
scripts/agent_step.sh "tbcontrol: models/tbc_services.py — опрос Zabbix через mTLS" models/tbc_services.py docs/TBControl/MTLS_SOURCE.md
```

Если среди путей общий файл — `--shared`, и правка в нём обязана быть точечной
(одна строка вызова, append, якорь по уникальной строке).

Начало и конец сессии (и перед любым длинным ответом владельцу):

```bash
scripts/agent_audit.sh
```

Нашёл чужое незакоммиченное/незапушенное — **не трогать**, назвать владельцу в
первом же ответе. Своё — запушить сейчас.

## 5. Чужой код в параллельных проектах — конкретные запреты

1. **`git checkout <ревизия> -- путь` на рабочем дереве запрещён даже для
   «восстановления».** Правильно: `git show <ревизия>:путь > /tmp/x`, `diff` с текущим,
   перенести нужные куски точечно. Так 02.09 надо было возвращать `docs/TBControl/`.
2. **Никаких `.env`, wallet-символьных ссылок, ключей внутри worktree сверх
   `.gitignore`.** 02.09 в worktree скопирован `.env` и сделан symlink wallet — они
   не попали в git, но `git status` потом показывал чужой мусор в чужом каталоге.
   Если нужно — `WALLET_DIR`/`.env` из корня проекта через переменные окружения.
3. **Общий каталог `/Users/pt/Projects.AI/Artgranit` стоит на чужой feature-ветке
   (28.10: `feat/autopark-module`).** В нём ничего не делать; `main` живёт в
   `Artgranit-core`. Переключать его — только владелец.
4. **В чужих worktree не бывает «починить на минутку».** Незакоммиченное в
   `Artgranit-core` и `Artgranit-restore` 28.10 — чьё-то; команда для них одна:
   сообщить.
5. **Merge в `main` — только 3-way по блокам** (`docs/Git/RESTAURARE_2026-10-22.md`);
   конфликтный блок решает дата коммитов, обе нужные правки совмещаются руками.
6. **Файлы через shell = невидимы для hook.** Любой `cat >`, `sed -i`, python-патч
   → сразу `scripts/agent_step.sh`.

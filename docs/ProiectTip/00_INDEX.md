# Типовой проект «Магазин и бэк-офис на вашей ERP» — пакет документов

*Версия 1.0 · 25.10.2026 · образец внедрения — OfficePlus (GRECU OFFICE GROUP SRL, Бэлць)*

Этот пакет позволяет взять проект officeplus.md как **типовой** и повторить его для
другой компании с учётной системой UNA.md / Oracle: оптовика, магазина канцтоваров,
стройматериалов, техники, сети точек продаж. Каждый документ есть в двух форматах:
**Markdown** (редактировать, хранить в git) и **HTML** (открыть в браузере, распечатать,
переслать).

| № | Документ | Для кого | Что внутри |
|---|---|---|---|
| 1 | [Маркетинговые материалы](01_MARKETING.md) | собственник, продажи, маркетолог | позиционирование, одностраничник, коммерческое предложение, посты, объявления, сценарий демо, шаблон под нового клиента |
| 2 | [Документация собственника бизнеса](02_GHID_PROPRIETAR.md) | владелец, директор | что даёт система, ежедневный контроль, переключатели, деньги, закон, риски, что решает владелец |
| 3 | [Тиражирование типового проекта](03_REPLICARE.md) | собственник + внедренец | как развернуть то же самое для другой компании: шаги, сроки, что меняется, чек-лист приёмки |
| 4a | [Инструкция покупателя (RO / RU)](04_INSTRUCTIUNI_CUMPARATOR.md) | клиенты магазина | каталог, поиск, корзина, рассрочка, кабинет, ассистент, cookie |
| 4b | [Инструкция сотрудника бэк-офиса](05_INSTRUCTIUNI_OPERATOR.md) | менеджеры, оператор, бухгалтер | ежедневные задачи по экранам, e-Factura, цены, импорт, поставщики, пауза сайта |

# 1. Маркетинговые материалы типового проекта

*Для собственника, отдела продаж и маркетолога. Всё готово к использованию — поля в
фигурных скобках `{…}` заменяются данными конкретного клиента.*

## 1.1 Позиционирование одной фразой

> **Интернет-магазин, кабинет клиента, рассрочка и e-Factura — прямо на вашей учётной
> системе. Цены, остатки и заказы — те же, что в учёте, в ту же секунду. Запуск — за дни.**

Три варианта под аудиторию:

| Кому | Что говорим |
|---|---|
| Владельцу торговой компании | «Ваш склад уже знает всё о товаре. Мы показываем это покупателю — без второй базы и ночных выгрузок.» |
| Финансовому директору / бухгалтеру | «Входящие накладные e-Factura — в учёт за минуты; заказ с сайта сразу становится документом.» |
| Внедренцу / разработчику | «Модуль — это одна папка. Подключается к ядру сам, не трогает чужой код.» |

## 1.2 Что именно получает клиент (список для КП)

| Блок | Возможности | Доказательство на OfficePlus |
|---|---|---|
| **Витрина** | каталог на 3 языках, поиск по релевантности, фото из фидов поставщиков, карточки с ценой и наличием (свой склад + склад поставщика), сравнение, избранное, мобильная версия с нижней панелью | 200 000+ позиций |
| **Продажи** | корзина, оплата картой MAIB/MIA, **цена в рассрочку** у каждого товара (EasyCredit, Iute, Microinvest, MAIB), порог рассрочки красным, коммерческое предложение в PDF | заказ → счёт в ERP |
| **Кабинет клиента** | история заказов, документы, данные компании по IDNO | |
| **Ассистент на сайте** | поиск по складу, корзина, КП в PDF, уведомление менеджеру в Telegram | |
| **Учёт и государство** | e-Factura (три пути импорта входящих), штрихкоды EAN-13 по правилу дома, цены по правилу владельца | 47 накладных, 352 позиции за раз |
| **B2B** | API для партнёров (совместим с Ultra B2B API V1), синхронизация каталога поставщика | |
| **Маркетинг** | автопубликация в соцсети, SEO-карта сайта, воронка продаж, учёт рекламы (SEOForge) | |
| **Закон и безопасность** | баннер согласия на cookie (новый закон о персональных данных), пауза сайта одним переключателем, скрытый вход в WordPress | |
| **Эксплуатация** | мониторинг серверов (TBControl), резервные копии, документация каждого изменения | 1355 автотестов |

Цифры платформы на 25.10.2026: **30 модулей, 179 рабочих экранов, 1355 автотестов,
191 файл схемы Oracle, ~91 000 строк кода**, три боевых контура.

## 1.4 Коммерческое предложение — шаблон

> **{Название компании клиента}** · коммерческое предложение · {дата}
>
> **Задача.** У вас учёт в UNA.md на Oracle и {N} товарных позиций. Нужен интернет-магазин,
> где цены и остатки совпадают с учётом, а заказ сразу становится документом.
>
> **Решение.** Типовой проект «Магазин и бэк-офис на вашей ERP» (образец — officeplus.md):
>
> | Этап | Срок | Результат |
> |---|---|---|
> | Подключение к вашей базе | 1 день | сервер, домен, SSL, доступ к Oracle |
> | Витрина и кабинет | 1–3 дня | ваш каталог, цены, остатки на сайте |
> | Оплата и рассрочка | 2–5 дней | договоры с банком/кредиторами — со стороны клиента, подключение — наше |
> | e-Factura, ассистент, соцсети | по выбору | модули включаются по одному |
> | Обучение | 1 день | сотрудники бэк-офиса, инструкции в комплекте |
>
> **Демо — бесплатно, на ваших данных, за один день.** Ничего в вашей базе не меняется.
>
> Контакты: {телефон} · {email} · {сайт}

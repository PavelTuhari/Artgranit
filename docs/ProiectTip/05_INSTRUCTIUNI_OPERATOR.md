# 4b. Инструкция сотрудника бэк-офиса

*Для менеджеров, оператора магазина и бухгалтера. Короткие сценарии «что сделать» —
со ссылками на подробные гиды. Вход: <https://officeplus.md/login> (тестовый контур —
<https://nufarul.eminescu.md/login>, та же база).*

## 0. Где что находится

После входа в боковой панели — все модули; полный список — карта системы
<https://officeplus.md/UNA.md/orasldev/modules>. Основные экраны:

| Роль | Экран |

## 1. Ежедневно: товары, цены, остатки

**Экран «Marfă / Stoc»** в бэк-офисе — весь каталог в таблице, слева дерево групп.

| Задача | Как |
|---|---|
| Найти товар | строка поиска: название / артикул / штрихкод; или клик по группе слева |
| Посмотреть карточку | клик по строке → «Fișa produs»: штрихкоды, тексты RO/RU/EN, отзывы, история цен |
| Поправить текст для сайта | в карточке — вкладка языка → **💾 Salvează (limba curentă)** |
| Цены на дату | фильтр «Prețuri la data» |
| Новые поступления | ☑ «Doar produse noi» |
| Почему товара нет на сайте | у него нет цены (Listă de prețuri) или группы (Nomenclator / Grupe) |

## 2. Загрузка прайса поставщика

1. Бэк-офис → **Import (asistent)** — 4 шага: **Sursă** (источник) → **Mapare** (какая колонка — артикул, название, цена, остаток) → проверка → запуск.
2. Повторная загрузка того же прайса безопасна: новые позиции получают карточку и штрихкод, у существующих меняется цена, только если она отличается.
3. Каталог дилера Ultra обновляется отдельно: <https://officeplus.md/UNA.md/orasldev/partner/> → «Integrare Ultra» (инструкция — `docs/Partner/ULTRA_ACTUALIZARE_INSTRUCTIUNE.html`).

## 3. Заказы с сайта

| Шаг | Где |
|---|---|
| Новый заказ приходит уведомлением в Telegram / на почту | настройки — экран уведомлений |
| Заказ виден в воронке и в учёте (документ-счёт) | Воронка, Журнал |
| Зависшие заказы (нет оплаты / отгрузки) | Воронка → «зависшие» |
| Клиент-компания | Клиенты: поиск по IDNO, данные из реестра |

**Коммерческие предложения ассистента:** приходят в Telegram с номером, клиентом и
ссылкой на PDF. Перезвонить клиенту, оформить заказ в учёте.

## 4. Рассрочка

1. Заявка клиента появляется в «Рассрочка» и уходит кредитору.
2. Ответ кредитора (одобрено / отказ) виден в заявке.
3. Пакеты и наценки кредиторов — в том же экране; **порог рассрочки** — настройка `CREDIT_MIN_ORDER`.
4. Цена в рассрочку считается одинаково на витрине, в корзине и в счёте — менять её «вручную» в счёте нельзя.

## 5. e-Factura (бухгалтер)

**Входящие накладные из файла SFS:**

1. Скачать XML с портала e-Factura.
2. <https://officeplus.md/UNA.md/orasldev/efactura/> → импорт файла → **анализ**: поставщики находятся по IDNO, товары — по точному совпадению названия.
3. Подтвердить создание недостающих карточек и документов прихода. Новые карточки получают штрихкод EAN-13 и цену продажи по правилу владельца (цена закупки / (1 − %)).
4. Проверить документ в учёте: штрихкоды и цены во всех строках.

**Исходящие:** инструкция бухгалтера — `docs/Partner/EFACTURA_INSTRUCTIUNI_CONTABIL.md`
(<https://officeplus.md/UNA.md/orasldev/b26docs/Partner/EFACTURA_INSTRUCTIUNI_CONTABIL.md>).

## 6. Сайт: тексты, баннеры, чат, пауза

| Задача | Где |
|---|---|
| Контакты, баннеры, блоки главной | Настройки витрины |
| Часы работы в шапке | настройка `SHOP_HOURS` (например `1-5=09:00-18:00;6=09:00-15:00;7=`) |
| JivoChat, Google Analytics | экран уведомлений (`SHOP_JIVO_ID`, `SHOP_GA_ID`) — запускаются только с согласия посетителя |
| **Поставить сайт на паузу** | <https://officeplus.md/UNA.md/orasldev/sitepause/> → «⏸️ Pune site-ul pe pauză»; свой текст RO/RU — по желанию |
| Снять паузу | там же → «▶️ Redeschide site-ul» (действует ≤ 20 с; вход в WordPress открывается тем же переключателем) |
| Проверить, как видит покупатель | открыть сайт в приватном окне (вошедшие сотрудники видят магазин и во время паузы) |

## 7. Соцсети и реклама

- Соцсети: модуль публикует разделы и бестселлеры по расписанию; ключи страниц — у администратора.
- Реклама: в SEOForge заводятся кампании и бюджет; затраты и результат — план/факт, ROI по каналам.
- Ссылки в рекламе — с метками `utm_source / utm_medium / utm_campaign` (схема — `docs/Marketing/KIT_CONTINUT.md`, раздел D3); источник визита учитывается только с согласия на cookie «Marketing».

## 8. Частые вопросы

| Вопрос | Ответ |
|---|---|
| Клиент видит одну цену, в счёте другая | проверить, не изменилась ли цена в Listă de prețuri на дату заказа; цена в рассрочку — по действующему пакету |
| В документе нет штрихкода | у карточки нет основного штрихкода — см. `docs/Partner/EFACTURA_CODURI_DE_BARE.md` |
| Сайт показывает «lucrări tehnice» | включена пауза — экран паузы |
| Ассистент не находит товар | у товара нет цены или он архивный |
| Покупатель жалуется на окно cookie | это требование закона; выбор меняется по ссылке «Setări cookie» внизу сайта |

## 9. Правило для всех сотрудников

Ничего не удалять из учёта «на всякий случай»: карточки архивируются (`ISARHIV`), а не
удаляются; при сомнении — спросить администратора.

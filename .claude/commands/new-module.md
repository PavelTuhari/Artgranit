Создай новый изолированный модуль Artgranit по правилам `AGENTS.md` и
`docs/GIT_WORKFLOW.md` (раздел 4). Аргументы: `$ARGUMENTS`.

Шаги — строго по порядку, ничего не пропускать:

1. Выполни `python scripts/new_module.py $ARGUMENTS` из корня репозитория.
   Скрипт сам создаст worktree `../Artgranit-<ключ>` на ветке `feat/<ключ>`,
   каркас `modules/<ключ>/`, `tests/test_<ключ>.py`, `docs/<Модуль>/`,
   сделает первый коммит и push. Если скрипт завершился ошибкой — покажи
   её владельцу и остановись, не чини руками общий каталог.
2. Перейди работать в `../Artgranit-<ключ>` (все дальнейшие правки — только
   там). Запусти `pytest tests/test_<ключ>.py` и убедись, что тесты изоляции
   зелёные.
3. Спроси у владельца одной репликой, что модуль должен делать (сущности,
   экраны, интеграции), если это не следует из названия. Технические
   развилки решай сам.
4. Проектируй по CLAUDE.md: нормализованные таблицы с префиксом модуля в
   `modules/<ключ>/sql/`, свой установщик, документация в `docs/<Модуль>/`
   с журналом изменений. В `app.py`, `deploy_oracle_objects.py`, общих
   шаблонах и меню — ничего.
5. После каждого законченного шага — `git add <свои пути> && git commit &&
   git push`. Перед сдачей: `git diff --name-only main HEAD` — только свои
   пути; `git log origin/feat/<ключ>..HEAD` — пусто.

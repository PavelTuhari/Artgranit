2. Методика

  1. pytest (98 тестов): чистые правила (EAN-13, SKU, распределение затрат, цены, сверка), генерация ZPL/TSPL/PDF, отправка на TCP-принтер, слой данных SQLite, HTTP-сценарии всех страниц, полнота переводов RU/RO/EN, миграция старой базы, изоляция от общего кода портала Artgranit.
  2. Сквозной прогон (tools/e2e.js, 27 шагов): приложение запускается на чистой базе, браузер проходит весь процесс как оператор — поставка → упаковочный лист → разбор мешков → сканер → сверка → цены → карточки → каталог → этикетки всех форматов → печать на сетевой принтер → настройки и справочники; затем все экраны на румынском и английском и мобильная ширина. Каждый шаг проверяется утверждением и сохраняется скриншотом.
  3. Нативное приложение (tools/desktop_e2e.py, 18 шагов, Xvfb): программа сама нажимает кнопки, заполняет поля, протаскивает мышью элементы в редакторе этикеток, выгружает и загружает Excel/CSV, печатает на сетевой «принтер»; затем обходит все 8 вкладок на румынском и английском и проверяет, что ни одна подпись интерфейса не осталась на русском.
  4. Установка (tools/install_check.py, 7 шагов): установщик в чистую домашнюю папку, ярлыки, запуск установленной программы ярлыком, удаление; сборка PyInstaller и запуск бинарника без системного Python.
  5. Визуальная проверка: скриншоты и изображения этикеток просмотрены; найденные по ним недочёты внесены в раздел 5.

7. Что не проверялось

  • Печать на физических Zebra и TSC: принтеров в среде испытаний нет. Проверены структура ZPL/TSPL (тесты), доставка задания по TCP (поддельный принтер) и вид этикетки в PDF. Перед вводом в работу — пробная печать одной этикетки и её сканирование.
  • Отрисовка ZPL в онлайн-просмотрщике labelary.com: отправка данных во внешний сервис в среде испытаний запрещена.
  • Запуск на Windows и macOS: испытания проводились на Linux (Ubuntu 24.04, Xvfb). Для Windows и macOS проверено, что установщик формирует правильные файлы (.bat с CRLF, TexFlow.app с Info.plist и иконкой) — тесты test_installer_windows_and_mac_scripts; ярлыки Windows (.lnk через PowerShell) и запуск на этих ОС не проверялись. Сборка PyInstaller выполнена только для Linux; для Windows (.exe) и macOS (.app) — шаблон GitHub Actions .github/workflows/texflow-desktop.yml, собирает и запускает их на своих ОС на каждый push.
  • Системная печать PDF (кнопка «Печать на системный принтер») — вызывает lp / печать Windows; в среде испытаний системного принтера нет.
  • Схема процесса на странице «Инструкция» в самом приложении рисуется библиотекой mermaid с CDN; без интернета показывается её текст. В HTML-документации схемы встроены готовыми SVG и работают без интернета.
  • Нагрузочное тестирование не проводилось: приложение рассчитано на 1–5 рабочих мест одного склада.

Инструкция оператора приёмки

Русский · Română · English

Цель — разобрать мешок за минуты, а не за часы. Каждую вещь при этом нужно занести как вариант «модель · цвет · размер» со штрихкодом и ценой.

Подготовка рабочего места

  • Ноутбук или ПК с TexFlow (python run.py). Если рабочих мест несколько: python run.py --host 0.0.0.0, на остальных открыть http://IP-ноутбука:5077.
  • Ручной сканер штрихкодов в режиме клавиатуры с суффиксом Enter. Такой режим у большинства сканеров стоит по умолчанию.
  • Термопринтер Zebra или TSC с рулоном 58×40 мм либо обычный принтер с листами A4.
  • Большой стол и ящики с подписями по категориям: футболки, джинсы, платья…

Шаг 1. Создать поставку

«Поставки» → «Новая поставка».

Поле Пример Зачем
Номер TR-2026-11-01 ссылка в документах
Поставщик Istanbul Tekstil карточки товара
Страна Турция / Китай страна происхождения
Валюта, курс USD × 17.8 пересчёт закупки в местную валюту
Фрахт, Таможня, Брокер, Прочее 4500, 1200, 800, 0 в местной валюте, войдут в себестоимость
Распределять затраты по стоимости дорогие вещи несут больше затрат. «По весу» — если платили за кг
Мешков 4 создать мешки 1..4 сразу (если листа нет)

Шаг 2. Загрузить упаковочный лист

Лист от поставщика обычно приходит в Excel. Его нужно сохранить как CSV: «Файл → Сохранить как → CSV (разделитель — точка с запятой)».

Нужные колонки (порядок любой, лишние игнорируются):

Колонка Варианты заголовка
мешок bag_no, мешок, bag, çuval, 包
категория category, категория, kategori, 类别 — код (TSH, JNS) или название из справочника
описание description, описание, açıklama, 品名
кол-во (обязательно) qty, кол-во, adet, pcs, 数量
цена за шт unit_price, цена, fiyat, 单价
вес, кг weight_kg, вес, ağırlık, 重量

Лист называется примерным: «футболки — 120 шт» без цветов и размеров. Этого достаточно. Цвета и размеры появятся при разборе, а количества будут сверены в шаге 4.

Если категория не распознана, будет предупреждение. Такую категорию можно добавить в «Справочниках» и загрузить лист заново.

Шаг 3. Разобрать мешок

Страница поставки → «Разобрать» у мешка.

Вещь уже есть в базе (например, вторая партия той же модели): отсканировать этикетку или штрихкод, добавится +1 шт. Ответ появится под полем сканера: ✓ — принято, ✗ — нет такого кода.

Новая модель:

  1. Разложить содержимое мешка на столе по моделям. Внутри каждой модели — по цветам, внутри цвета — по размерам. Это главный приём: сначала разложить, потом вводить количество, а не вводить каждую вещь по одной.
  2. Заполнить «Новая модель»: название (как будет на ценнике), категорию (от неё зависят размерная шкала и наценка) и, если известен, состав. Артикул создаётся сам (TSH0007). Закупочная цена подставится из упаковочного листа по категории, её можно исправить.
  3. Откроется матрица. Кликнуть по нужным цветам — каждый станет строкой. Цвета сгруппированы как на сайте Zara: Белый (белый, молочный, экрю), Бежевый (бежевый, песочный, кэмел), Синий (синий, тёмно-синий, деним)…
  4. Ввести количество в ячейки «цвет × размер». Enter переходит в следующую ячейку, стрелки двигают курсор. Итоги по строкам и столбцам считаются сразу.
  5. Ctrl+Enter или «Записать». Кнопка «Записать и печатать этикетки» сразу открывает печать именно этой партии.

Ошибся: в журнале приёмки нажать × у строки или ввести в матрицу отрицательное число (−2).

Когда мешок пуст — «Мешок разобран».

Шаг 4. Сверка с листом

Страница поставки, блоки «Сверка по категориям» и «Сверка по мешкам»:

  • совпало — всё хорошо;
  • недостача (красным) — пришло меньше, чем в листе: основание для претензии поставщику;
  • излишек — пришло больше;
  • нет в листе — категория не была заявлена.

Лист примерный, поэтому расхождение в 2–5 % обычно нормально.

Шаг 5. Цены

«Цены» у поставки. По каждой модели видно:

  • закупку в валюте;
  • себестоимость в местной валюте с пошлиной и долей фрахта, таможни и брокера;
  • наценку категории;
  • предложенную цену (уже округлённую: 189.90, 249.90…);
  • фактическую наценку после округления.

Можно вписать свою цену в поле «Своя цена». Затем «Записать цены в карточки».

Если цену модели менять нельзя (акция, договорная цена), её фиксируют в карточке модели галочкой «Зафиксировать цену». Пересчёт такую цену не трогает.

Наценки категорий меняются в «Справочниках». Округление (шаг, хвост .90/.99) и НДС — в «Настройках».

Шаг 6. Этикетки

  • На всю поставку или мешок — со страницы поставки. Этикеток столько, сколько принято штук.
  • На модель — из карточки модели.
  • Одна этикетка — кнопка «этикетка» у варианта (например, на замену испорченной).

Перед печатью можно поправить число копий у каждой строки.

Выбор формата:

  • ZPL — для Zebra;
  • TSPL — для TSC;
  • PDF A4 — для листов самоклеящихся этикеток. Печатать в масштабе 100%. «Начать с ячейки» позволяет допечатать начатый лист;
  • PDF рулон — для печати через драйвер или в виртуальный принтер.

Кнопки: «Открыть / скачать», «Скачать файлом», «Печать на принтер» (по адресу из настроек).

Подробности по принтерам — LABELS.md.

Шаг 7. Каталог

«Каталог» — карточки моделей с цветами, ценой и остатком. Внутри карточки:

  • цвета с кодами и группами;
  • сетка размеров (зачёркнут — нет в наличии);
  • таблица SKU и EAN;
  • кнопка печати карточки.

Экспорт CSV — полный список вариантов (артикул, цвет, размер, SKU, EAN, цена, остаток) для загрузки в интернет-магазин или кассу.

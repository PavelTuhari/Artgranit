4. Себестоимость и цены

себестоимость = закупка × курс
             + пошлина категории
             + доля затрат поставки
цена = себестоимость × (1 + наценка)
     × (1 + НДС) → 189.90

Затраты распределяются по стоимости, по штукам или по весу мешков.

  • Напечатать этикетки на термопринтере или на обычном принтере

Решение: один процесс

1Мешки из Турции / Китая
2Поставка: курс, фрахт, таможня, брокер
3Примерный лист CSV → мешки
4Разбор: матрица цвет × размер или сканер
5Сверка с листом
6Себестоимость → цена

Сервер и интернет не нужны: один файл базы SQLite, запуск на ноутбуке склада, несколько рабочих мест по локальной сети. Полные блок-схемы — в документации.

4. Себестоимость и цены

себестоимость = закупка × курс
             + пошлина категории
             + доля затрат поставки
цена = себестоимость × (1 + наценка)
     × (1 + НДС) → 189.90

Затраты распределяются по стоимости, по штукам или по весу мешков.

Этикетки: четыре формата

ZPL → Zebra · TSPL → TSC · PDF A4 → обычный принтер · PDF-рулон → виртуальный принтер / драйвер. Печать по сети (порт 9100), через CUPS или в папку; копии — одной командой.

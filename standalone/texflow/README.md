# TexFlow — приёмка одежды из мешков, каталог, цены и этикетки

**Русский** · [Română](README.ro.md) · [English](README.en.md)

Автономное веб-приложение на **Python + Flask + SQLite**. Нужен для быстрой
обработки одежды, которая приходит из Турции и Китая в мешках, где всё лежит
вперемешку, а к поставке есть только **примерный** сводный упаковочный лист.

TexFlow ведёт товар через пять шагов:

1. принимает его по мешкам, раскладывая каждую модель по матрице «цвет × размер» (как в Zara);
2. сверяет факт с упаковочным листом;
3. считает себестоимость с учётом импортных затрат;
4. ставит цены по наценкам категорий;
5. печатает этикетки на **Zebra (ZPL)**, **TSC (TSPL)** или в **PDF** —
   листом A4 для обычного принтера или рулоном для виртуального принтера.

Интерфейс на трёх языках: **русский, румынский, английский**. Переключатель
RU / RO / EN стоит в шапке. Названия цветов, категорий и размерных шкал
переведены, а цвет на этикетке можно печатать на любом из трёх языков.

Сервер и интернет не нужны: один файл базы `instance/texflow.db`, запуск с
ноутбука. Приложение не связано с порталом Artgranit/Oracle и не трогает его
код. Всё лежит в `standalone/texflow/`.

## 1. Установка и запуск

Нужен Python 3.10 или новее (проверено на 3.13).

```bash
cd standalone/texflow
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python run.py --demo               # откроет http://127.0.0.1:5077/ с демо-поставкой
```

| Параметр | Что делает |
|---|---|
| `--host 0.0.0.0` | открыть доступ с планшетов и ПК в локальной сети, например для сканера на втором рабочем месте |
| `--port 5077` | порт |
| `--db путь.db` | другой файл базы, например отдельная база на сезон |
| `--demo` | загрузить демо-поставку `DEMO-TR-01`: 3 модели, принятые штуки, цены |
| `--no-browser` | не открывать браузер автоматически |

Переменные окружения: `TEXFLOW_DB` — путь к базе, `TEXFLOW_PDF_FONT` — свой
TTF-шрифт для PDF.

**Резервная копия** — скопировать файл `instance/texflow.db`. Если приложение
запущено, надёжнее так: `sqlite3 instance/texflow.db ".backup backup.db"`.

## 2a. Языки

| Где | Как |
|---|---|
| Интерфейс | переключатель **RU / RO / EN** в шапке; запоминается в браузере. Язык по умолчанию — «Настройки → Язык интерфейса» |
| Справочники | у цвета, группы цветов, категории и шкалы есть `name` (RU), `name_ro`, `name_en`; пустой перевод → русское название. При добавлении в «Справочниках» есть поля RU / RO / EN |
| Модель | в карточке модели — название и состав на RO и EN (пусто → основное). Каталог, разбор и цены показывают название на языке интерфейса; поиск — по любому языку |
| Этикетка | «Настройки → Язык названий цветов на этикетке»: цвет, название модели и состав печатаются на этом языке («Negru», «Tricou basic») |
| Упаковочный лист | заголовки CSV понимаются и по-румынски: `sac;categorie;descriere;cantitate;preț;greutate`; категорию можно указать румынским или английским названием |
| Новая строка интерфейса | в шаблоне — `{{ _('Русский текст') }}`, перевод — в `texflow/i18n_catalog.py`; без перевода тест `test_every_ui_string_translated` падает |

## 3. Как работать (кратко)

Полная инструкция — [docs/OPERATOR_GUIDE.md](docs/OPERATOR_GUIDE.md).

1. **Поставки → Новая поставка.** Указать номер, поставщика, страну, валюту и
   курс к местной валюте. Затраты в местной валюте: фрахт, таможенные сборы,
   брокер, прочее. Выбрать способ распределения затрат: по стоимости, по
   штукам или по весу мешков.
2. **Упаковочный лист.** Загрузить CSV: `мешок;категория;описание;кол-во;цена;вес`.
   Заголовки можно писать по-русски, по-английски, по-турецки или по-китайски.
   Кодировки UTF-8, cp1251, cp1254 и GB18030 определяются сами. Мешки создаются
   автоматически.
3. **Разбор мешка.** Если вещь уже заведена, достаточно отсканировать её EAN
   или SKU — добавится +1 шт. Новую модель заводят в форме «Новая модель»:
   кликнуть по нужным цветам, затем ввести количества в матрицу размеров.
   Enter — следующая ячейка, Ctrl+Enter — записать. Закупочная цена
   подставляется из упаковочного листа по категории.
4. **Сверка** на странице поставки, по категориям и по мешкам: «совпало»,
   «недостача», «излишек», «нет в листе».
5. **Цены.** Себестоимость → наценка категории → НДС → красивая цена
   (например, 189.90). Можно вписать свою цену или зафиксировать её в карточке.
6. **Этикетки** печатаются на всю поставку, на мешок, на модель или на один
   вариант. Количество этикеток равно числу принятых штук.

## 4. Модель данных (SQLite, нормализованная)

| Таблица | Сущность |
|---|---|
| `suppliers` | поставщики |
| `size_scales`, `sizes` | размерные шкалы: буквенная XXS–3XL, женская EU 32–48, мужская 44–58, джинсы W24–38, детская по росту 86–164, обувь 35–46, ONE |
| `color_families`, `colors` | группы цветов в стиле Zara (Белый, Чёрный, Бежевый, Синий…) и цвета с кодами `001`, `800`, `401`… |
| `categories` | категория → размерная шкала, наценка %, пошлина %, ТН ВЭД |
| `shipments` | поставка: валюта, курс, фрахт/таможня/брокер/прочее, способ распределения, статус |
| `bags` | мешки поставки: номер, вес, статус (`closed` → `sorting` → `done`) |
| `packing_lines` | строки примерного упаковочного листа |
| `products` | модель: артикул, название, категория, состав, закупка, розничная цена, флаг фиксации |
| `variants` | вариант «цвет × размер»: уникальные `sku` и `ean13` |
| `intake_items` | журнал приёмки: сколько штук какого варианта достали из какого мешка; закупка; себестоимость |
| `label_jobs` | журнал печати |
| `settings` | настройки приложения: бренд, НДС, округление, размеры этикеток, адреса принтеров, языки |

Остаток не хранится отдельным полем: это `SUM(intake_items.qty)` по варианту.
Исправление пересчёта — строка с отрицательным количеством или удаление строки
журнала.

**SKU** = `АРТИКУЛ-КОДЦВЕТА-РАЗМЕР`, например `TSH0001-800-M`.
**EAN-13** — внутренний, с префиксом `200` (диапазон 20–29 GS1 оставляет для
внутреннего использования магазина) и правильной контрольной цифрой. Префикс
меняется в настройках.

## 5. Формулы

```
закупка_лок   = закупка_вал × курс
пошлина       = закупка_лок × пошлина_категории %
доля_затрат   = (фрахт + таможня + брокер + прочее) × база_позиции / Σ база
                 база: стоимость (qty × закупка_лок) | штуки | вес (вес мешка × доля штук в мешке)
себестоимость = закупка_лок + пошлина + доля_затрат / qty
цена_расчёт   = себестоимость × (1 + max(наценка_категории, мин_наценка) %) × (1 + НДС %)
цена          = ⌈(цена_расчёт + хвост) / шаг⌉ × шаг − хвост        (шаг 10, хвост 0.1 → 189.90)
```

## 7. Чек-лист после установки

1. `python -m pytest -q` — все тесты зелёные.
2. `python run.py --demo` открывает главную; в «Каталоге» 3 модели с ценами.
3. «Этикетки» → поставка `DEMO-TR-01` → «PDF A4» → «Открыть»: лист 3×8 со
   штрихкодами. Сканер должен читать EAN с бумаги.
4. Для Zebra/TSC: адрес принтера в «Настройках», затем печать одной этикетки
   (кнопка «этикетка» у варианта в карточке модели) и проверка, что она
   сканируется.

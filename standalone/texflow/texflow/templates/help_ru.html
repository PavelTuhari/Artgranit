Коротко

  1. Поставка. Меню «Поставки» → номер, поставщик, валюта и курс к местной валюте, затраты в местной валюте. Метод распределения: по стоимости (дорогие вещи несут больше), по штукам, по весу мешков.
  2. Упаковочный лист. CSV/TSV из Excel: мешок; категория; описание; кол-во; цена; вес. Понимает заголовки на русском, румынском, английском, турецком и китайском. Неизвестные категории подсвечиваются.
  3. Разбор. «Разобрать» у мешка. Повторный товар — сканером. Новая модель — форма «Новая модель», затем клик по цветам (строки) и ввод количеств по размерам (колонки). Enter — следующая ячейка, Ctrl+Enter — записать. Ошибся — введите отрицательное число или удалите строку журнала.
  4. Сверка. На странице поставки: по категориям и по мешкам — «недостача», «излишек», «нет в листе».
  5. Цены. «Цены» → предложение по каждой модели. Можно вписать свою цену; цену в карточке можно зафиксировать (замок), тогда пересчёт её не трогает.
  6. Этикетки. На всю поставку, мешок, модель или один вариант; количество — по принятым штукам. Форматы: ZPL (Zebra), TSPL (TSC), PDF A4, PDF рулон.

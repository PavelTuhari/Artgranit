Setările integrării

Utilizatorul API se creează în e-Factura de persoana cu rol Manager (Director): Setări → Utilizatorii companiei → „CREEAZĂ UN UTILIZATOR API". Până la completare modulul funcționează în gol: se poate vedea XML-ul care ar pleca, dar nu se trimite nimic.

Semnatarii — DOUĂ conturi API

Factura fiscală se semnează de obicei de două persoane (director și contabil-șef), iar e-Factura ține cozi separate pentru fiecare (Order 1 și 2 la GetInvoicesForSigning) — de aceea se înregistrează două conturi API. Al doilea este opțional: dacă lipsește, se folosește primul.

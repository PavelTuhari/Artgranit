Contragenti rulează pe calculatorul dvs. (Windows, din instalatorul MSI) și ține un API local pe portul 9393. «Creează client» îl deschide cu filtrul introdus; după «Vernuti contragent» cardul XML ajunge aici și clientul se salvează în Oracle (CRM_*), cu deduplicare după IDNO. Dacă browserul nu poate apela API-ul local, se folosește revenirea (return_to) — Contragenti trimite browserul înapoi aici cu datele.

      
      
 macOS .command ⊞ Windows .bat 🐧 Linux .py
         — același script Python (doar biblioteca standard): găsește sau descarcă Contragenti, îl pornește și revine în CRM.
